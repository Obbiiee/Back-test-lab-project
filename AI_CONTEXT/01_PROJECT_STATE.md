# Actual product and repository state

- React 19 / Vite 8; installed Lightweight Charts 5.2.1 (package range ^5.2.1).
- XAUUSD approximately ten years: 3,486,461 validated M1 candles; eleven aggregated timeframes; progressive historical loading.
- Active frontend replay: `frontend/src/market/useReplayMarket.js` loads date-selected M1 chunks, aggregates the revealed prefix, steps timeframe buckets, loads older history, extends forward chunks, restores/saves replay date. Workspace uses commit-acknowledged playback at 1×/2×/5×/10×/20×, play/pause/resume and manual stepping. Previous is allowed only without orders, positions or closed trades. Forward hints are validated against revealed arrays before native chart updates or trading suffix processing; uncertain transitions retain full reference behavior. Aggregation, seven indicator calculators and native Volume still recompute fully. Archived/backend modules are not evidence of active frontend capabilities.
- Trading: market/limit/stop and pending simulation, buy/sell positions, entry/SL/TP, independent Long/Short Risk/Reward, native markers and price lines.
- Economic news: canonical local JSON import, separate versioned IndexedDB/recovery, strict per-field availability and labeled read-only retrospective research, filters/windows, official time-anchored primitive markers, acknowledged manual-step event navigation and derived-only entry/exit context. Synthetic fixtures are not economic history. Evidence/input contract/limits: [news report](../docs/PHASE14_5_ECONOMIC_NEWS.md). Operational completion belongs only to the phase authority.
- Existing trading terminal includes Analysis derived from the same canonical paper account: completed-position grouping across partial exits, basic realized metrics, balance/drawdown curve, position/exit detail and canonical journal notes, raw/grouped CSV export. Partial exit rows remain distinct from completed positions. Existing start/exit replay reset actions require confirmation when trading activity exists. No account schema/engine or analytics store was added. Exact contracts, browser evidence and limitations: [checkpoint report](../docs/PHASE14_TRADING_UX_BACKTEST_ANALYSIS.md).
- Drawing: DrawingManager/Registry, immutable TIME + PRICE Trend Line, Horizontal Line, Vertical Line, Rectangle, Fibonacci Retracement, Arrow, Text and Measure models, official series primitive, separate creation/interaction controllers, A/B creation, draft, selection, shared projection/hit testing, four virtual Rectangle corner handles, endpoint/body drag and axis-constrained line editing, keyboard delete, ESC/cancel and cross-timeframe projection.
- Legacy custom indicator runtime remains retired. A separate Indicator Engine foundation accepts only chart-visible candles, validates immutable configs/input/output and owns official line/histogram series lifecycle. Production catalog contains exactly SMA, EMA, Bollinger Bands, RSI, MACD, ATR and Stochastic. Overlay series stay in the price pane; each pane-type instance owns a dedicated official pane with native resize. Runtime-only multiple instances support add/edit-Apply/hide/remove; reference indicators remain test-only. Native Volume remains separate.

All eight drawing types persist in a separate version-1 localStorage namespace across reload, timeframe and replay changes. Canonical commit snapshots provide independent Undo/Redo (100 actions, runtime only), lock/unlock and hide/show. Malformed/future storage is preserved without overwrite; valid records can be recovered read-only. Text has a minimal placement/edit form; Fib levels and Measure labels are derived. No magnet integration, additional advanced tools, indicator/pane persistence, pane merging/reordering, full properties UI, object tree or legacy migration. Existing trading controls/history remain separate and do not imply these features exist for the new drawing domain.

Phase 7.5 repository cleanup removed ten unreachable copies already preserved byte-identically in Phase 3. At that historical checkpoint, the production import graph contained 41 files. Current graph ownership is recorded in [architecture](02_ARCHITECTURE.md); compatibility exports, datasets and archives remain protected. Root/frontend/docs READMEs identify the single active source; repository boundary tests and ignore rules protect future hygiene.
