- XAUUSD approximately ten years: 3,486,461 validated M1 candles; eleven aggregated timeframes; progressive historical loading.

Forward hints are validated against revealed arrays before native chart updates or trading suffix processing; uncertain transitions retain full reference behavior. Runtime-only multiple instances support add/edit-Apply/hide/remove; reference indicators remain test-only. Native Volume remains separate.

No magnet integration, additional advanced tools, indicator/pane persistence, pane merging/reordering, full properties UI, object tree or legacy migration. Existing trading controls/history remain separate and do not imply these features exist for the new drawing domain.
