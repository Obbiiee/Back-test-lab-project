## UX decisions already set — do not ask founder to redesign

- One React+Vite app, Lightweight Charts; same auth and backend for desktop/mobile/PWA/Capacitor shells.
- Method first; Free Style+Protocol behavior fixed. One instrument/Session with source version pin. 16 catalog slots visible truthfully, not all enabled.
- Laptop = chart-first professional terminal with left drawing rail, upper timeframe+indicators, right order/details, bottom resizable Open/Pending/Closed/Journal/Analysis. Mobile = chart-first touch with Draw/Indicator sheets, safe replay controls, full-screen order review sheet, 5-tab bottom nav, landscape chart. Tablet responsive intermediate. App V1 PWA; store builds later Capacitor target.
- Nine registered research drawings and two Long/Short planning types must be reliable. Professional sixteen extensions are scoped separate milestones; never advertise they exist before rendering+math/persistence tests.
- Seven existing indicators must be functional. Fifteen future professional options are not clickable until qualified, especially volume-dependent.
- Exact order path always Draft → backend Review → user Confirm → backend receipt → reveal market tick; no user action or draw creates a filled trade directly. No client P&L/cash authority, no fake future quote.
- Replay: Play/Pause/Step + **one button Jump 72h UTC**, independent pending unchanged on no event, no OCO/auto-cancel. UTC seek is separate and respects fork after financial event.
- Brand/tokens and metallic original R preserved; no new chart framework, no unsolicited icon/font library, avoid duplicating backend/financial data in front end.
