## 2. Frozen wire rules shared across every endpoint

- `schemaVersion` integer and a pinned generated OpenAPI schema SHA; `contractVersion` explicitly changed for incompatible semantics. Existing canonical wire names and hashes **remain unchanged** where locked.
- ID type UUID/string per *actual* domain source; `workspaceId` and `sessionId` require authenticated membership and Session Method/data pin checks on **every read and write**.
- Money/lot/price = canonical decimal strings or scaled integer with explicit versioned tick/quote context; timestamps UTC ns strings for exact equality and ISO UTC for display. Never use JS floating point as settlement truth.
- Responses bounded and paginated; event, candle, chart object and metadata payload not conflated; published old Session and order receipts remain backwards readable.
- Financial POST requires `commandId`/existing domain idempotent identity, expected Session revision and immutable review ID/hash; server atomically commits events+receipt. A request timeout is **UNKNOWN** until command/Session/job inspected.
- UI drawing/indicator writes use separate **`mutationId` + `expectedObjectRevision` CAS**; they never increment financial event ledger or execute a trade.
- Errors: `code`, `detail`, `requestId` and optionally `currentRevision`/`retryAfterSeconds`, field errors only when safe; distinguish 401 unauthenticated, 403 forbidden, 404 foreign/missing masked, 409 revision mismatch, 413 quota/body cap, 422 invalid input, 429 busy, 503 unavailable, and separate `UNRESOLVED_SOURCE`/`NO_CONVERSION_FEED`.
- No private auth token, raw future ticks, original licensed source, foreign drawings or private notes in URL/query, browser Cache Storage, CDN cache or public object-store link.

## 4. Frozen DTO shape for cross-device drawing and indicator settings (conceptual)

### `ChartObjectV1`

```json
{
  "schemaVersion": 1,
  "objectId": "uuid",
  "sessionId": "uuid",
  "kind": "trend-line",
  "anchors": [
    {"timeNs":"1730419200000000000","priceDecimal":"2000.100"},
    {"timeNs":"1730422800000000000","priceDecimal":"2003.400"}
  ],
  "style": {
    "lineColor":"#0965FF","lineWidthPx":3,"linePattern":"DASHED",
    "lineOpacity":0.8,"fillColor":null,"fillOpacity":0,
    "text":{"bold":false,"italic":false,"fontSizePx":14,"align":"CENTER"},
    "labels":{"showPrice":true,"showTime":false},
    "levels":[]
  },
  "visible":true,"locked":false,"zOrder":12,
  "datasetVersion":"pinned exact hash",
  "revision":5
}
```

**Example numbers above are *synthetic wire fixtures*, not market price or source evidence.** Validate kind-specific allowed anchors and fields; the JSON's string prices are chart coordinate values, **not a trade execution request**. Do not require all style fields for every kind; per-kind registry with safe defaults, additive versioned fields and stable old saved schema support.

### `IndicatorInstanceV1`

```json
{
  "schemaVersion":1,"instanceId":"uuid","sessionId":"uuid",
  "indicatorId":"MACD","calculationVersion":"MACD-v1",
  "inputs":{"fastPeriod":12,"slowPeriod":26,"signalPeriod":9},
  "outputStyles":[
    {"key":"macd","color":"#38bdf8","widthPx":2,"visible":true},
    {"key":"signal","color":"#f59e0b","widthPx":1,"visible":true},
    {"key":"histogram","positiveColor":"#68d6bd","negativeColor":"#ff9aa5","visible":true}
  ],
  "pane":{"id":"oscillator-2","order":2,"heightRatio":0.25,"scale":"RIGHT"},
  "source":"CLOSE","revision":8
}
```

**Storage stores settings, not per-Symbol caches of the entire indicator output for every trader.** Qualified shared derived candle caches keyed by exact dataset/version/timeframe/derivation version, with frontend indicators recalculated only on bounded reveal pages. Unsupported volume-based indicators get `DATA_CAPABILITY_MISSING` with actual volume-kind proof, never fake ticks-as-traded-volume.

### `CandlePageV1`

Fields `sessionId, datasetId, datasetVersion, feedId, instrumentId, timeframe, priceBasis, coverage, startNs, endNs, throughNs, executionAuthority, volumeKind, quality, candles:[{timeNs,openDecimal,highDecimal,lowDecimal,closeDecimal,incomplete}], nextPageToken`. **Guarantee:** response cannot contain a candle based on a quote after the Server Session's committed reveal cursor; a historical read-only context separate endpoint has `executionAuthority:false` and visual context styling. Use data normalization distinct from full V2 tick event proof; financial execution uses exact private tick reducer, not the displayed midpoint OHLC.

### `ChartMutationReceiptV1`

Fields `mutationId, objectId/instanceId, previousRevision, currentRevision, contentHash, saveStatus`; 409 returns current revision without leaking foreign data. On laptop+HP concurrent edit only one CAS succeeds; losing browser fetches latest object and prompts to reconcile rather than overwriting a style silently. Delete is a tombstone with safe Undo policy in its own revision scope, not a financial ledger reversal.
