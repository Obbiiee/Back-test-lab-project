# Phase 5 — Drawing foundation

Completed locally on 2026-10-02. Scope: official Lightweight Charts 5.2.1 series primitives and one Trend Line. No community drawing dependency or proprietary chart source added. This report and the previously completed Phase 4 changes are included in the repository commit for Phase 5.

1. **Files created:** `frontend/src/drawings/DrawingTypes.js`, `DrawingRegistry.js`, `DrawingManager.js`, `models/TrendLine.js`, `primitives/TrendLinePrimitive.js`, `timeCoordinates.js`, `TrendLineCreation.js`, `useDrawingTools.js`; `frontend/tests/phase5.test.mjs`; `frontend/tests/browser/phase5.html`; this report and the Phase 5 evidence files in `docs/`.
2. **Files modified in Phase 5:** `frontend/src/CandleChart.jsx`, `frontend/src/FigmaWorkspace.jsx`, `frontend/package.json`, `OPEN_SOURCE_NOTICES.md`. Existing chart and toolbar received small integration changes. Trading, replay and market modules were not rewritten.
3. **DrawingManager:** owns canonical objects, attached primitives and an ephemeral draft. Provides add/get/getAll/remove/clear, attach/detach and subscriptions. Detach clears rendering references while retaining completed models. React integration belongs to a separate hook. The manager has no order, Risk/Reward, replay, indicator or storage responsibilities.
4. **Registry:** maps a validated type to model and primitive factories. Only `trend-line` is registered. Unknown types, duplicate registrations/IDs, Long Position and Short Position are rejected.
5. **Official APIs:** verified against installed 5.2.1 typings and implementation: `attachPrimitive`, `detachPrimitive`, `attached`, `detached`, `updateAllViews`, `paneViews`, pane renderer `draw`, `requestUpdate`, canvas target `useMediaCoordinateSpace`, `timeToCoordinate`, `coordinateToTime`, `coordinateToLogical`, `priceToCoordinate`, `coordinateToPrice`, `subscribeClick`, `subscribeCrosshairMove` and their unsubscribe counterparts. No autoscale contribution is supplied; annotations do not expand price autoscale. References: [series primitives](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives), [canvas rendering target](https://tradingview.github.io/lightweight-charts/docs/plugins/canvas-rendering-target), [official v5.2.1 trend-line example](https://github.com/tradingview/lightweight-charts/blob/v5.2.1/plugin-examples/src/plugins/trend-line/trend-line.ts).
6. **Custom glue:** original application model/manager/registry, creation controller, React hook and deterministic timestamp projection. The primitive follows official interfaces; it does not copy the retired renderer or add an SVG drawing overlay. Pointer movement requests primitive updates without notifying React on each move. Drawing operations never call market-series `setData` or recreate the chart/series.
7. **Creation:** existing Trend Line toolbar action enables A/B creation; a dashed primitive previews B. Second anchor creates a solid line and returns to Cursor. ESC cancels unfinished creation. Drafts never enter completed objects, storage or undo history. Draft survives replay candle updates.
8. **Coordinates:** immutable, JSON-serializable numeric UTC seconds and prices. Exactly two completed anchors; no canonical pixels. Options, visibility/lock schema fields and creation timeframe metadata are separate from anchor coordinates.
9. **Zoom:** PASS, projection follows chart transformation; canonical anchors unchanged.
10. **Pan/history:** PASS, backward loading was exercised into April/May from June. Offscreen objects remain in the manager with identical anchors. See `PHASE5_HISTORY_TEST.jpg` and `PHASE5_ANCHOR_PROOF.json`.
11. **Resize/scales:** PASS, viewport resize and price/time scale changes preserve anchors. Projected pixels are recalculated by the primitive lifecycle.
12. **Replay:** PASS, both completed anchors remain identical after progression. In-progress draft is not reset by a new candle array.
13. **Timeframes:** PASS, M15 → H1 → M15 retains exact timestamps/prices. Installed `timeToCoordinate` returns null for timestamps without an exact datapoint. Minimal glue interpolates between actual official coordinates of neighboring timestamps; it never snaps or rewrites the model. Edge timestamps use deterministic neighboring spacing for extrapolation. This also avoids incorrectly treating a local array index as a global chart logical index. See `PHASE5_COLD_LOAD_PROOF.json` and `PHASE5_TIMEFRAME_TEST.jpg`.
14. **Legacy storage:** isolated browser fixture seeded mixed known/unknown legacy records and backups. `PHASE5_STORAGE_BEFORE.json` and `PHASE5_STORAGE_AFTER.json` are byte-identical, SHA-256 `FD0C976E32DC92C8F72EE5D6EA8707E38409D0B85412990BD47AF39AD95D9060`. These are test-origin snapshots, not a claim to have inspected every production user key. No migration or new Trend Line persistence was introduced. Existing trading persistence remains owned by the trading compatibility layer.
15. **Trading regression:** PASS, Long/Short creation, entry/SL/TP adjustments, existing lock controls, order popup, pending-order placement/cancellation, market simulation, replay valuation, native price lines and trade markers. New manager contains only Trend Lines. Evidence: `PHASE5_ORDER_TEST.jpg`, `PHASE5_TRADING_REGRESSION.jpg`.
16. **Build:** PASS (`npm run build`).
17. **Lint:** PASS (`npm run lint`). Git whitespace check PASS.
18. **Tests:** PASS Phase 5 manager/schema/lifecycle/projection/creation/isolation tests; Phase 4 retirement/preservation; trading separation; trading; 88 drawing geometry regression tests; market validation covering 3,486,461 M1 candles and 11 timeframes.
19. **Browser console:** final fresh-load tab on isolated port 5181 returned zero error entries after creation, timeframe roundtrip and replay. During development, changing the hook structure triggered an HMR hook-order error in an older tab; fresh load recovered and the final runtime check is clean. Legacy drawing and indicator runtimes remain retired.
20. **Screenshots:** `docs/PHASE5_TRENDLINE_PREVIEW.jpg`, `docs/PHASE5_TIMEFRAME_TEST.jpg`, plus history/order/trading screenshots listed above. Anchor evidence includes `PHASE5_ANCHOR_PROOF.json`, `PHASE5_FINAL_ANCHORS.json`, `PHASE5_COLD_LOAD_PROOF.json`.
21. **Limitations:** new drawings live in memory and are cleared by page reload; timeframe switches within the mounted chart retain them. Selection, drag, resize handles, properties, hide/lock controls, object-tree integration, undo/redo, magnet and migration for new drawings are intentionally absent. Existing toolbar bulk controls continue to target existing trading objects. Arbitrary-time projection is minimal interpolation/extrapolation, not calendar-aware reconstruction of unloaded history; insufficient data may produce no projection. Annotation clipping does not expand chart autoscale. No other drawing tools or indicators implemented.

Phase 5 stops here. Phase 6 requires a new instruction.
