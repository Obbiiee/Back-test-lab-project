# Phase 6 — Trend Line interaction

Completed 2026-10-03. Only the existing official-primitive Trend Line was extended. No new drawing type, persistence, indicator, backend or UI redesign was added.

1. **Files created:** `frontend/src/drawings/interaction/hitTesting.js`, `DrawingInteractionController.js`, `frontend/tests/phase6.test.mjs`, this report and `docs/PHASE6_*` evidence.
2. **Files modified:** `DrawingManager.js`, `primitives/TrendLinePrimitive.js`, `timeCoordinates.js`, `useDrawingTools.js`, `components/CandleChart.jsx`, `frontend/package.json`. CandleChart changes only pass the container to the hook and expose diagnostic selection/focus attributes.
3. **Interaction architecture:** canonical model → independent interaction controller → official series primitive. Controller owns hover/hit/drag and event arbitration; renderer only draws projected lines/handles. Pointer movement updates the primitive imperatively; React receives selection, completed drag and other low-frequency changes.
4. **Selection ownership:** manager runtime `selectedId`, at most one object; never serialized into the model. Empty chart pointer down and ESC deselect. Delete clears selection. Switching away from cursor tools cancels the controller and clears selection.
5. **Hit testing:** projected finite AB segment, perpendicular distance with segment parameter constrained to [0,1]. Selected Anchor A then Anchor B have priority over body. Selected drawing wins overlap ties; otherwise newest drawing wins. Zero-length segments are safe. No canonical geometry is derived from DOM bounds.
6. **Tolerance:** body 6 CSS/media pixels; handles 9 CSS/media pixels. Browser client coordinates and primitive `useMediaCoordinateSpace` share CSS-pixel units, so tolerances are not multiplied by DPR. DOM bounds are used only to translate event coordinates into pane coordinates.
7. **Selected primitive:** line width gains one pixel and two restrained five-pixel circular handles appear. Official update lifecycle reprojects them after zoom/pan/resize. Deselection removes handles. No drawing SVG overlay added.
8. **Anchor A:** browser and automated PASS; only A changes, B remains value-identical.
9. **Anchor B:** browser and automated PASS; only B changes, A remains value-identical.
10. **Body translation:** capture original anchors and initial pointer TIME + PRICE. Continuously invert the Phase 5 timestamp projection using actual neighboring chart coordinates. Apply the same pointer-derived delta in epoch seconds and price to both original anchors. This preserves calendar-time separation and price difference, subject to floating-point rounding. It does not translate candle indices or snap anchors. Across compressed session gaps, the body may not remain under the pointer with perfectly constant pixel slope; canonical calendar-time relationships take precedence.
11. **ESC/cancel:** active drag restores original anchors and retains selection; a subsequent ESC deselects. Creation mode binds its existing ESC cancellation instead of interaction. Pointer cancel, lost capture, window blur, tool/timeframe change and unmount restore unfinished drag. Normal release commits. Domain and bound-event tests exercise ESC/pointer cancellation and restoration; browser checks exercise ESC deselection and creation cancellation. No undo integration.
12. **Delete:** Delete/Backspace removes only the selected manager object. Inputs, textarea, select, contenteditable and editable ARIA controls are excluded. Clicking a drawing focuses the chart without scrolling, fixing stale input focus. Browser verified input protection and successful subsequent deletion. Trading shortcuts are blocked only when this controller actually handles a drawing command.
13. **Chart pan arbitration:** capture-phase pane pointer listener claims a drawing hit, captures pointer and temporarily disables pressed-mouse/touch panning. Exact previous scroll options are restored on commit/cancel/cleanup. Empty pane events propagate normally and deselect. Merely selecting does not globally disable pan. Price/time scale events are excluded by pane bounds. Browser empty-pan historical loading passed.
14. **Risk/Reward arbitration:** events targeting existing `[data-drawing-type]` trading geometry or `.trading-levels` are excluded from drawing interaction. Drawing mode and Risk/Reward creation mode bind mutually exclusive controllers. Existing trading overlay remains its own owner. At overlapping interactive trading geometry, trading has priority. Browser verified Trend Line drag changes no Risk/Reward anchors, and SL/TP drag changes no Trend Line anchors. Keyboard capture prevents double deletion across domains.
15. **Replay:** browser selected-line advancement retained exact anchors and handles. Existing market position valuation changed with replay normally. Drawing draft/interaction does not modify replay or market data.
16. **History:** empty-chart pan loaded April/May history from June; completed object survived with valid canonical anchors. Returning to the daily viewport allowed reselect and drag. Empty-background pointer down intentionally deselects before panning; offscreen projection does not delete the object.
17. **Timeframe roundtrip:** created/edited M15 line → H1 endpoint drag → M15. Resulting H1 model values remained exactly equal in M15. Fractional epoch timestamps are retained; no resnapping.
18. **Anchor evidence:** `PHASE6_INTERACTION_PROOF.json` records creation, A drag, B drag, body drag, H1 drag, M15 return and drag after history. Screenshots show corresponding primitive states. The first attempted Delete while input focus remained active correctly did not delete; after the focus correction, chart click followed by Delete was verified successful.

Body translation uses epoch-time differences over irregular/compressed time axes.
